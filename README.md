# 📂 Personal Projects

A structured **monorepo** containing hands-on projects spanning multiple core Computer Science domains.  
This repository serves as my personal portfolio to demonstrate practical engineering skills in **Object-Oriented Programming**, **Data Structures & Algorithms**, **Web Development**, **Backend APIs**, **Databases**, **Automation**, and **Data Science**.

---

## 🗂️ Repository Structure

The projects are categorized by domain to maintain a clean and professional workflow:

```
.
├── Automation-Scripts/              # Python scripts for daily tasks
│   ├── File-Organizers/             # Automate folder/file cleanup
│   └── Web-Scrapers/                # Extract data from websites
│
├── Backend-APIs/                    # Server-side development
│   ├── Authentication-Systems/      # JWT, OAuth, Login/Register flows
│   └── REST-API-Basics/             # CRUD operations, Express/Flask
│
├── Competitive-Programming/         # DSA practice for coding rounds
│   ├── Easy-Problems/               # LeetCode Easy, CodeChef Beginner
│   ├── Medium-Problems/             # LeetCode Medium, Intermediate
│   └── Hard-Problems/               # Advanced algorithmic challenges
│
├── Data-Science-ML/                 # Analytics and AI/ML experiments
│   ├── Data-Analysis/               # Pandas, Matplotlib, EDA
│   └── Machine-Learning-Models/     # Regression, Classification, Scikit-learn
│
├── Data-Structures-Algorithms/      # Foundational CS logic & problem-solving
│   ├── Dynamic-Programming/         # Memoization, Tabulation, Knapsack
│   ├── Graph-Tree-Problems/         # BFS, DFS, BST, Traversals
│   ├── Searching-Sorting/           # Binary Search, Merge Sort, Quick Sort
│   └── String-Algorithms/           # Pattern matching, Palindrome, Anagrams
│
├── Database-Projects/               # Structured and unstructured data
│   ├── NoSQL-MongoDB/               # Document-based schemas
│   └── SQL-Query-Exercises/         # Joins, Subqueries, Indexing
│
├── OOP-Projects/                    # Object-Oriented Design & Architecture
│   └── library-management-system/   # Full OOP project (Books, Users, Transactions)
│
└── Web-Development/                 # Frontend and interactive UIs
    ├── Frontend-UI/                 # HTML, CSS, React components
    └── JavaScript-Games/            # Interactive browser-based games
```

---

## 🚀 Features of This Repository

- **Modular Structure**: Each folder contains isolated projects with their own READMEs (where necessary).
- **Placement-Focused**: Designed specifically to showcase skills required for internships and campus placements.
- **Clean Version Control**: Empty directories are tracked using `.gitkeep` files to preserve the structure on GitHub.
- **Scalable**: New projects can be added to their respective categories without cluttering the root.

## 💻 How to Explore

1.  **Clone the repository** to your local machine:

```
git clone https://github.com/anshumanhq/Personel-Projects.git
cd Personel-Projects
```

2.  **Navigate** to any domain folder and open the project in your preferred IDE (e.g., VS Code).

3.  **Run** Python/JavaScript projects directly from their subdirectories.
